## 📑 Required Report Sections (IEEE 2-Column Format)
1. **Title**: Project Title, Course, Group Name ("Theoutliers"), and Member Details.
2. **Abstract**: Comprehensive summary of the completed project, methodology, and final results.
3. **Keywords**: 4–6 relevant keywords.
4. **Introduction**: Problem definition, literature review/background, motivation, and scope.
5. **Methodology**: Detailed explanation of the end-to-end technical implementation, equations, filters, deep learning or classical DIP methods.
6. **Results**: Quantitative evaluation (tables, metrics like PSNR, SSIM, IoU, Accuracy) and qualitative evaluation (output images, comparative graphs).
7. **Discussions**: Deep dive into findings, failure cases, ablation studies, and performance trade-offs.
8. **Conclusion & Future Scope**: Key takeaways, project conclusions, and avenues for future work.
9. **References**: Complete list of IEEE formatted references.
