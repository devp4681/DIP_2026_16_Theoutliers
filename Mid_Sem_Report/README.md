## 📑 Required Report Sections (IEEE 2-Column Format)
1. **Title**: Project Title, Course, Group Name ("Theoutliers"), and Member Details.
2. **Abstract**: Brief summary of the problem statement, proposed solution, and initial results (typically 150–250 words).
3. **Keywords**: 4–6 relevant keywords (e.g., *Digital Image Processing, Image Segmentation, Filtering*).
4. **Introduction**: Problem formulation, significance, motivation, and objectives.
5. **Methodology**: Detailed explanation of algorithms, image processing pipelines, architectures, or mathematical formulations used.
6. **Results**: Visual results, graphs, and performance metrics obtained so far.
7. **Discussions**: Interpretation of preliminary findings, challenges encountered, and comparisons.
8. **Conclusion**: Summary of progress made and roadmap toward end-sem completion.
9. **References**: Citations conforming to IEEE citation style.
